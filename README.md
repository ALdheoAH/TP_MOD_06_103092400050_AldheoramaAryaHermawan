1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya! [5 Poin]
   Jawab : JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif. JavaScript dapat digunakan untuk merespons tindakan pengguna, memvalidasi data pada formulir, menampilkan pesan, dan mengubah isi halaman tanpa harus memuat ulang halaman secara keseluruhan.
2. Jelaskan secara singkat apa itu jQuery dan kegunaannya! [5 Poin]
   Jawab : jQuery adalah library JavaScript yang membantu programmer menulis kode JavaScript dengan lebih sederhana. jQuery menyediakan fungsi untuk memilih elemen HTML, menangani kejadian seperti klik tombol, mengubah tampilan halaman, serta membuat efek animasi.
3. Jelaskan perbedaan JavaScript dan jQuery! [10 Poin]
   Jawab : JavaScript adalah bahasa pemrograman, sedangkan jQuery adalah library yang dibuat menggunakan JavaScript untuk mempermudah penulisan kode. JavaScript dapat digunakan tanpa jQuery, tetapi jQuery membutuhkan JavaScript agar bisa bekerja.
